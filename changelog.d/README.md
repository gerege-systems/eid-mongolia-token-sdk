# changelog.d

Нэг өөрчлөлт = нэг фрагмент: `changelog.d/<YYYY-MM-DD>-<сэдэв>.md`.

Агуулга: юу · яагаад · хаана (файл/PR) · хэрхэн шалгасан · үлдсэн. Нууц, дэд бүтцийн мэдээлэл бичихгүй.

PR бүр дор хаяж нэг шинэ фрагмент нэмнэ (CI-ийн `changelog` job шалгана). `CHANGELOG.md`-г feature салбарт
засахгүй — main дээр фрагментүүдийг огноогоор нэгтгээд устгах нэг commit-оор л шинэчилнэ.
