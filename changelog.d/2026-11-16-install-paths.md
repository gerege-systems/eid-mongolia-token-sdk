# README: суулгах зам бүрийг тусад нь, энгийн хэрэглэгчид ойлгомжтой болгосон

- **Юу:** `README.md`-ийн эхэнд «Суулгах — аль замаар вэ» (ногоон «Code → Download ZIP» зөвхөн эх код гэсэн
  анхааруулга, Releases ба шууд татах холбоосууд, хэн аль замаар явах хүснэгт). §3-ийг зам бүрээр нь дэд хэсэг болгосон
  (Windows A браузер / B PowerShell / C эх код, macOS A Terminal / B браузер / C эх код, command-line хэрэгсэл) —
  тус бүр шаардлага → дугаартай алхам → «Амжилттай бол» → түгээмэл саад. Checksum / runner / provenance-ийн тайлбарыг
  «Татсан файлыг шалгах» хэсэгт, шаардлага ба бичдэг файлуудыг тусдаа хэсэгт шилжүүлсэн (баримт хасаагүй). Windows:
  zip дотор `eid-token-test-windows-x64\` хавтас, «Unblock»-ийг задлахаас өмнө (эсвэл `Unblock-File`,
  `Get-ChildItem -Recurse | Unblock-File`), хоёр анхааруулгын цонх, `%TEMP%\eid-token-test-<guid>\opensc.conf` түр файл.
  §4-т эх код хаанаас авахыг, §7-д Windows-ийн жишээ, `--help`, UTF-8 консол, §8-д «exe олдохгүй» ба «Windows: апп
  эхлэхгүй» мөр нэмсэн. `windows/README.md`-ийн эхэнд 5 алхамтай «Хурдан эхлэх».
- **Яагаад:** гадны хэрэглэгч «Code → Download ZIP»-ээр эх кодын архив татаж exe олоогүй; суулгах заавар §3-ийн нягт
  догол мөрөнд, шууд холбоосгүй, Windows-ийн командгүй байсан.
- **Хаана:** `README.md` (эхний хэсэг, «Агуулга», §3, §4, §7, §8), `windows/README.md`.
- **Хэрхэн шалгасан:** Windows-ийн алхмуудыг v0.1.0 release дээр Windows 11 дээр шалгасан (zip-ийн хавтасны бүтэц,
  Unblock, анхааруулгын цонх, PowerShell-ийн checksum ба `Expand-Archive`, `eid-token-check`-ийн exit code-ууд). Explorer-оор
  давхар дарж нээх ба SmartScreen-ийн цонх энэ удаа шалгагдаагүй. Холбоос / anchor-уудыг гараар тулгасан.
- **Үлдсэн (кодын ажил, энд засаагүй):** v0.1.0 аппын лог `starting 0.2.0.0` гэж хэвлэдэг (хувилбарын мөр зөрүүтэй);
  түр `eid-token-test-<guid>` хавтсууд хэзээ ч устдаггүй.
- **Дахин шалгасан:** шинэ бичвэрийг алхам алхмаар дагаж Windows 11 дээр дахин шалгаад засварласан: Extract All-аар
  задлахад ижил нэртэй хавтас хоёр давхар үүсдэг (exe-ийн бүтэн зам), Unblock хийсэн zip-ийн файлд Mark-of-the-Web
  байхгүй тул цонх гарахгүй, Unblock алгасвал «Open File - Security Warning» гардаг; `windows/README.md`-ийн үндсэн
  README руу холбоосыг zip дотор ажиллахгүй байсан тул бүтэн URL болгосон, Windows A / B холбоосыг салгасан.
