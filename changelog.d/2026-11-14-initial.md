# 2026-11-14 — eID token SDK: first version

- **What:** integrator guide (README.md), public trust chain (`trust/`: 01 root, 02–04 intermediates), read-only
  test apps for macOS (SwiftUI) and Windows (WinUI 3) with the verifier as a copyable folder on each platform, the
  `eid-token-check` command-line tool on both platforms, the OpenSC 0.26.1 PKCS#11 module (Windows DLL; macOS
  build script), CI (`token-sdk-macos`, `token-sdk-windows`, `changelog`, `gate`).
- **Why:** third-party relying parties read the eID USB token and log users in with their own server-side checks.
- **Rules:** AUTH certificate issued directly by the pinned eID Mongolia Issuing CA (04) only; KeyUsage exactly
  digitalSignature; EKU contains clientAuth; one subject serialNumber starting with `PNOMN-`; OCSP nonce required for
  the AUTH certificate (optional for the 04-against-03 check); origin validated inside the verifier; responder
  certificate rules; inclusive validity bounds; strict DER; the same order and reasons on both platforms.
- **Verified:** the PR CI pipeline (unit tests on both platforms, app and CLI builds, package contents).
- **Open:** no code signing / notarization; no installers.
